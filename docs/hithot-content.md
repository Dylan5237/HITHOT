# 内容分类与评分 v3

本站面向医疗信息化软件厂商的产品、研发和经营人员。评分标准以 `industry/prompts/selection-score.md` 为准；板块、关注视角与重点厂商别名维护在 `industry/content.ts`。

- 板块为单选；关注视角可多选，第一个是首要视角。
- 评分两次独立调用均返回分数、板块、关注视角和推荐理由。分数仍取两次平均值；展示分类和推荐理由取分数较高的一次，相同时取第一次，避免拼接出模型未给出的结论。
- 分析与发布投影均保存板块、关注视角；公开出口从发布读取层获取。首页可组合 `board` 与 `perspective` 查询参数，视角筛选也包含次要视角。
- 日报按首要视角分为“市场经营”“产品技术”两栏，条目保留另一视角标签；事件去重规则继续生效。
- 评测冻结前临时统一门槛为 70。最终门槛必须由冻结金标的双轮评测决定，不能把旧版本校准结果直接用于新版提示词。

已有文章不会因为提示词更新自动重算。材料、提示词、模型均匹配的文章可调用 `queueProcessing(id, { step: 'selection' })` 零调用重判；不匹配的须正常重评。历史内容及回填内容的发布必须关闭推送。数据库变更、回填及批量重跑前，保留可验证的数据库备份；日报重生成使用原有修订记录保留旧版。

数据库新增字段使用 0090–0093 四条在线迁移，均为新增列，不删除历史数据。后端源码挂载部署还须同步 `apps/api/src` 和 `packages/contracts/src`；前端须构建后发布，不能只重启后端来更新页面。

## 公共信源采集

医疗行业的专用公开接口集中在 `modules/medical-sources/`，端点、证券代码和不可用原因维护在 `industry/medical-sources.ts`，启停状态同步到 `industry/sources.json`。巨潮公告只取规定类别和 PDF 首页文字；卫宁公开接口只取其公开摘要，不读取链接中的微信公众号文章。评级名单使用中国政府网公开检索，近 60 天没有匹配名单时保留零条，不伪造样例。

新增源先试抓，再调用 `collectMedicalSource(id, { process: false })` 回填。材料仍经过框架的身份、时间窗口、入库和历史标记；失败进入现有 fetch_runs、健康状态和下次抓取退避。仅跳过直接排队不代表自动扫描器停止，盲标前还须暂停正常 worker，防止提前评分。

所有信源采集、详情读取和图标请求通过统一采集 HTTP 层，先检查 robots.txt，同站子域及端口共享数据库请求锁，前一次响应结束后至少间隔 5 秒；robots 的更长 Crawl-delay 同样生效。0094 迁移新增请求时间表，无历史数据删除。验证码、401/403/429/202、频繁访问页会停止路径，不转用其他身份或正文中转。付费模型 HTTP 不走采集限速层。

采购公告解析采用机构字段白名单：采购人、省份、人民币金额、中标机构、产品线。先检查采购人类别、软件关键词、纯硬件/维护/耗材排除，再要求重点厂商中标或金额达到 500 万元；原始 HTML、联系人字段均不入库。当前采购端点尚未通过完整回填验证，保持停用；解析器通过本地合成材料验证不能代替真实接入验收。

7 个海外媒体/期刊源按 v3 要求停用，保留历史材料；HL7 International、Google Health 保留。药监局在入库前要求医疗软件或人工智能关键词。使用 seed 只插入新源，既有源停用与药监规则必须另行更新数据库，不能依赖重复 seed 覆盖管理员配置。

港交所使用条款禁止未经书面许可的程序化访问和文本挖掘，相关源停用。其他被 robots、访问限制或使用条款阻止的来源，以及尚未验证字段和分页的来源均保存具体原因，不能把“接口能返回”作为采集接入成功。
