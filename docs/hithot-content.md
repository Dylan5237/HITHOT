# 内容分类与评分 v3

本站面向医疗信息化软件厂商的产品、研发和经营人员。评分标准以 `industry/prompts/selection-score.md` 为准；板块、关注视角与重点厂商别名维护在 `industry/content.ts`。

- 板块为单选；关注视角可多选，第一个是首要视角。
- 评分两次独立调用均返回分数、板块、关注视角和推荐理由。分数仍取两次平均值；展示分类和推荐理由取分数较高的一次，相同时取第一次，避免拼接出模型未给出的结论。
- 分析与发布投影均保存板块、关注视角；公开出口从发布读取层获取。首页可组合 `board` 与 `perspective` 查询参数，视角筛选也包含次要视角。
- 日报按首要视角分为“市场经营”“产品技术”两栏，条目保留另一视角标签；事件去重规则继续生效。
- 评测冻结前临时统一门槛为 70。最终门槛必须由冻结金标的双轮评测决定，不能把旧版本校准结果直接用于新版提示词。

已有文章不会因为提示词更新自动重算。材料、提示词、模型均匹配的文章可调用 `queueProcessing(id, { step: 'selection' })` 零调用重判；不匹配的须正常重评。历史内容及回填内容的发布必须关闭推送。数据库变更、回填及批量重跑前，保留可验证的数据库备份；日报重生成使用原有修订记录保留旧版。

数据库新增字段使用 0090–0093 四条在线迁移，均为新增列，不删除历史数据。后端源码挂载部署还须同步 `apps/api/src` 和 `packages/contracts/src`；前端须构建后发布，不能只重启后端来更新页面。
