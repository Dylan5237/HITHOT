页首说明：

> 本站聚合公开信源，用模型生成中文摘要与精选，原文版权归各来源所有。网页、RSS、公开 API 与 MCP 均可匿名使用。

## 1. 内容与版权

本站展示的标题、摘要和推荐理由由模型根据公开来源生成，可能有误，重要信息请以原文为准。原文版权归各来源所有；站内只在来源允许时展示全文，其余只展示摘要和原文链接。

## 2. 不构成医疗建议

本站是医疗信息化行业的资讯聚合站，只报道 AI 在医疗信息化领域的政策、产品、落地与研究进展。

本站内容不构成诊疗建议、用药建议、医疗器械选型建议或投资建议，也不能替代执业医师、执业药师、医院信息部门或专业顾问的判断。模型生成的摘要可能出错、可能滞后、可能丢失原文的前提条件；涉及适应证、注册证号、临床数据、审批状态的内容，请以监管机构与厂商的原文为准。

本站不为任何依据本站内容做出的决策承担责任。如有健康问题，请就医。

## 3. 来源方的更正与下架

如果你是来源方，希望更正、下架或调整展示方式，请通过反馈页联系我们，我们会尽快处理。

报道涉及医疗不良事件、数据安全事件或个人隐私的，请在反馈中说明，我们会优先处理。

## 4. 使用本站的数据

**允许，无需另行取得同意**：个人阅读；医院、厂商与研究机构在内部做研究、评审、培训与选题参考时引用。请注明出处为本站并附原文链接。

**需要事先取得站长书面同意**：把本站内容（含标题、摘要、推荐理由与精选榜单）用于商业产品或服务；公开转载，包括公众号、媒体与自媒体账号；批量再分发或镜像整站；把站内内容用于训练或微调模型。

**不允许**：在面向患者的产品或宣传材料里引用本站内容。本站不是临床信息来源，模型摘要可能出错，第 2 节已说明本站内容不构成医疗建议。

取得同意的方式：通过站内「反馈」页说明用途、发布载体与使用范围，我们会回复是否同意及附带条件。

## 5. 接口与频率

RSS、公开 API 和 MCP 为匿名只读接口。请按响应中的缓存时间轮询，遇到 429 请遵守 Retry-After，不要并发重试。
