
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：产品名 / 系统名 / 公司名 / 机构名 / 文件与项目名。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是版本号 / 代号 / 没信息量的 teaser（如 "uAI 3.0"、"重磅发布"、"官宣"）时，结合【来源】和正文把主体补进标题。例：原标题 "uAI 3.0" + 来源 "联影智能" → "联影智能 uAI 3.0 发布"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体产品名时，用上位词（如"影像 AI 辅助诊断软件"）兜底，绝不凭"行业常识"编一个具体产品 / 版本 / 数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review / Benchmark 这类解释、分析、教程或评测标题，中文标题必须保留这个类型；不能因为正文谈到一个已经存在的产品、系统或新数据，就改写成“发布 / 推出 / 上线 / 获批”。只有原标题明确宣布了发布、推出、上线或获批，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的机构、产品、项目名。
   例：原标题 "How DAX Copilot documents patient encounters" → "DAX Copilot 如何记录患者就诊过程"，不能写成 "微软发布新版 DAX Copilot"。
   例：原标题 "Building an AI-enabled EHR workflow" + 来源和正文明确是卫宁健康 WiNEX → "WiNEX 如何构建 AI 电子病历工作流"，不能只写成缺主体的 "如何构建 AI 电子病历工作流"。
